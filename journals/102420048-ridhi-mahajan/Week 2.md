# Week 2: GitHub Setup and Initial Frontend Development
## Cloned GitHub Repository and Created Frontend

#### During the second week, the shared GitHub repository for the Smart Airport Management System (SAMS) was cloned and configured in Visual Studio Code.

#### The initial frontend development was started according to the project architecture and planned dashboard workflow.

### The work completed included:

#### Cloning the shared GitHub repository into Visual Studio Code.
#### Setting up the local development environment for frontend development.
#### Understanding the existing repository structure and project workflow.
#### Creating the initial Login interface for user authentication.
#### Creating the initial Dashboard interface as the foundation for the airport management system.
#### Organizing the frontend code within the shared project structure.
#### Committing and pushing the frontend work to GitHub so that all team members could access the latest changes and continue development collaboratively.
